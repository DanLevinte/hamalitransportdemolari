# Hamali Transport Demolări — site

Site static (HTML/CSS/JS, fără build) pentru https://hamalitransportdemolari.md/ — RO/RU.

- `index.html` — conținut
- `styles.css` — design
- `main.js` — interacțiuni + traducerea RU
- `images/` — poze (`.webp` folosite pe site, `.jpg` originale)

Lansare: se urcă tot folderul pe hosting. Previzualizare locală: `python -m http.server`.
